## Свои проекты

### [Istok](https://github.com/DotNotFact/istok-about)

Конструктор приложений для сенсорных экранов. Человек собирает приложение в браузере
из своих фото, видео, PDF и 3D-модели, а на выходе получает программу для Windows-стойки
или архив для браузера-киоска. Программист для правок не нужен, интернет на стойке тоже.
Подходит кофейне, магазину, выставке и офису продаж недвижимости, где покупатель сам
выбирает дом, этаж и квартиру.

`ASP.NET Core 10` · модульный монолит · `PostgreSQL` · `Redis` · `Next.js` · `Tauri 2` · `Rust` · `Docker` · GitLab CI

Код закрыт. Описание и живой пример - в [istok-about](https://github.com/DotNotFact/istok-about).

### [Pult](https://github.com/DotNotFact/pult)

Пульт для любого проекта. Открываете папку - он находит все команды (package.json,
Makefile, justfile, скрипты, CI) и объясняет каждую по частям: что делает, какие у неё
флаги, что поменяет на диске. Запускает с консолью, показывает пайплайн GitLab или GitHub
и короткие уроки по технологиям, которые есть в проекте. Объяснения лежат в JSON
и работают без интернета.

`Rust` · `Tauri 2` · `ratatui` · open source, MIT
